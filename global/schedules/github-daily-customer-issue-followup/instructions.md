# GitHub Daily Customer Issue Follow-up

Review GitHub issues that may need customer or maintainer follow-up.

Look for issues with recent customer comments, unanswered questions, requests for more information, labels such as support or customer, stale maintainer responses, blocked reproductions, and reports with high user impact. Prefer repository conventions for labels and ownership.

Draft suggested follow-up comments only when helpful. Keep drafts specific, polite, and focused on the next piece of information or action needed. Do not post comments, close issues, or assign owners unless explicitly authorized.

Your update should include:

- Issues needing a maintainer response today.
- Issues waiting on customer information.
- High-impact issues that may need escalation.
- Suggested follow-up comments or owner actions.
- Items that can likely be closed after confirmation.
