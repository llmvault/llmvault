# GitHub Weekly Issue Triage Sweep

Review open GitHub issues and prepare a weekly triage summary.

Prioritize issues that are new, unlabeled, reopened, stale, missing owner, missing reproduction details, duplicated by other reports, or blocked on maintainer response. Use repository issue templates, labels, milestones, and previous triage patterns when available.

Classify issues into useful buckets such as actionable bugs, needs more information, likely duplicates, documentation gaps, feature requests, support questions, and stale items. Do not apply labels, close issues, or comment unless explicitly authorized.

Your summary should include:

- Issues that need immediate maintainer attention.
- Issues that need more information from the reporter.
- Likely duplicates or related clusters.
- Suggested labels, owners, or milestones.
- Stale issues that should be closed, revived, or re-scoped.
