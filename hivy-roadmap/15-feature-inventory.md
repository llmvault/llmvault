## When a row can say “shipped”

The server contract and access checks work. Main user flows work on the named surfaces. Failures recover safely. Audit, cost, retention, and data location are defined. User and admin docs exist. Acceptance tests pass. Public copy says exactly what the feature does and where its limits are.
